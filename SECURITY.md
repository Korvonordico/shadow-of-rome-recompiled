# Security policy

## Supported versions

Only the latest release gets fixes. Please update to it before reporting.

## Reporting a problem

If you find something that could harm the people who use this project (for example a file in a release that should not be there, or a way the launcher or the game could be made to run other programs), please report it privately: open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not write it in a public issue.

This project is made by one person in their free time: every report is read, but an answer may take a few days.

Problems with the game itself (crashes, freezes, wrong graphics) are not security problems: report them in the [issues](../../issues/new/choose).
