# Contributing

Thank you for wanting to help! This is an unofficial PC port of Shadow of Rome (PS2), made by one person with the help of AI. Every kind of help is welcome, even if you do not write code.

## Ways to help

- **Play it and tell me what happens.** The game has not been played to the end yet, so every report helps. Open an [issue](../../issues/new/choose) with the "Game problem" form: what you did, what happened, your Windows version and your video card. A screenshot or a short video helps a lot.
- **Ask or chat in [Discussions](../../discussions).** Questions, ideas, how far you got in the game: Discussions is the place for them.
- **Fix something.** If you know how to fix a problem, you are welcome to send a pull request (see below).

## Before you start

- **No game files here.** Never add files from the game disc or its .iso to this project, not even small parts: everyone uses their own copy of the game.
- **Big changes:** open an issue or a discussion first, so we can talk about it before you spend time on it.

## Sending a pull request

1. Make a fork of this project (the **Fork** button at the top of the page) and work in a new branch.
2. Build and run the game as explained in [Building it yourself](README.md#building-it-yourself), and check that your change works in the game.
3. Changes to PS2Recomp or PCSX2 go in the patch files in [`patches`](patches); [`patches/README.md`](patches/README.md) explains what each one does.
4. In the pull request, explain in simple words what you changed, why, and how you tested it.
